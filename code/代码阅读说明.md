# 控制器源码阅读说明

本目录是本次实板验证使用的F28P550控制器工程，中文注释已直接加入自编写的7个核心源码/配置文件。本次仅增加注释，未改算法、数值常量、编译参数或现有.out文件；核验记录见上一级validation/comment_only_audit.json，原源码备份在validation/source_before_comments。

建议依次阅读：

1. `ex_adc_poll_4channels_main.c`：主入口、ADC、模式开关、Timer0/1/2、双缓冲、前馈、49.5 µs保护及主循环。
2. `include/imc_user_config.h`：HIL比例、电流保护、调制比步长、43/39 µs预算及计时阈值。
3. `source/imc_estimator.c`：DSOGI与公共幅值前馈。
4. `source/imc_gru.c`：16单元GRU的CPU前后处理和INT8 NPU调用。
5. `source/imc_cla_fnn.c`：CPU侧CLA启动、消息RAM协议及同帧结果校验。
6. `source/imc_fnn_task.cla`：CLA执行的稀疏FNN、去零序、幅值平方及矢量对投影。
7. `source/imc_gate_scheduler.c`：独立SVPWM/FNN路径、驻留时间取整、预算约束及门极事件生成。

## 模式与使能

|变量|数值|作用|
|---|---|---|
|g_estimatorMode|0 / 1 / 2|原始电压 / DSOGI / GRU16|
|g_modulatorMode|0 / 1|CPU SVPWM / 异步CLA稀疏FNN|
|g_pwmEnable|0 / 1|独立门极关闭 / 允许门极输出|
|g_controlEnable|0 / 1|控制计算禁止 / 允许|
|g_clearFaultRequest|1|请求在门极关闭且NPU可安全复位时清除锁存故障|

实板对比组合：DSOGI＋SVPWM=(1,0)，GRU＋FNN=(2,1)。改模式应先关闭门极；模式切换会复位估计器并撤销PWM使能，不能把修改g_activeEstimatorMode当作常规切换接口。使能PWM仍受预热完成、总控制使能及无故障等条件约束。

FNN是解析初始化的3→6→12→6稀疏ReLU网络，36个非零权重，CLA源码为其代数融合实现，不是最初的400权重训练网络。GRU保留16单元INT8 NPU模型，CPU负责激活与隐藏状态更新。

## IO与时间

- AO2/3/4接ADCINA0/4/5，三相电压比例0.002 V/V。
- AO5接ADCINA9，电感电流比例0.05 V/A。
- HIL AO偏置1.65 V、运行限幅0.1～3.2 V，须与HIL模型配置配套。
- G1～G6从GPIO0/1/2/3/10/11输出，接HIL DI1～DI6。
- 控制周期50 µs；计时器150 MHz，150计数=1 µs；整帧保护7425计数=49.5 µs。
- HIL实板测试编译分支保留负电流异常计数但不以负电流下限停机；正向过流仍保护，不应未经审查直接移用于真实功率装置。

## 构建与既有测试程序

构建脚本：上一级`scripts/build.py`。此前实板使用的文件为`build_physical_test/imc_ff_npu_f28p55.out`；强制物理门极为0的计时程序为`build_benchmark50/imc_ff_npu_f28p55.out`。两者不能混淆。
